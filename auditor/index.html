Unrip Protocol — Security Status

This page is an informational notice. It does not run vulnerability scans, penetration tests, transaction simulations, or cryptographic verification.

No security score, grade, test count, or “passed” status is reported here because none has been independently measured.

Before using this project

  • Keep autonomous signing disabled unless you have a dedicated, low-balance agent wallet and understand the risks.
  • Never place a seed phrase or private key in source code, issues, prompts, logs, or committed files.
  • Review every transaction in your wallet before signing.
  • Run the repository's tests and obtain an independent security review before handling real funds.

See the repository README for setup and security limitations.
