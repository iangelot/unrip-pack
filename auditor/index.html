Unrip security review notes

Important: This page is documentation only. It does not execute security tests, inspect the running service, verify deployment settings, or calculate a security score. No security certification or passing result is implied.

What this page is

This page records security-review scope and points operators toward the checks they must run independently. It is not a penetration-testing tool.

Before production use

  • Run dependency and static-analysis scans against the exact commit being deployed.
  • Verify OAuth redirect URI validation, PKCE, token expiry, session isolation, and rate limits.
  • Review CORS and allowed origins for the clients you actually support.
  • Confirm that logs never contain private keys, bearer tokens, seed phrases, or unnecessary wallet identifiers.
  • Keep private keys in a managed secret store. Never commit them or paste them into prompts, issues, or logs.
  • Use a dedicated low-balance wallet for testing. Require explicit wallet approval for every transaction unless autonomous signing is an intentional, separately reviewed feature.

Credentials and environment variables

Environment variable names such as AGENT_PRIVATE_KEY are configuration names, not credentials by themselves. Their values must remain outside the repository and be stored only in the deployment platform's secret manager.

Review status

No live audit has been performed by this page. Record test commands, tool versions, commit SHA, findings, and remediation evidence in a separate, reproducible security report.
